# Prompt para OpenCode — reconstrucción del incidente (Parte C.4)

Usarlo en una sesión **nueva**, adjuntando solo `log_simulacro_1_anonimizado.txt`, sin agregar contexto:

```
Te paso un fragmento de log de un servidor PostgreSQL 18. Los datos personales están
anonimizados. Usando únicamente lo que el log muestra:
1. Reconstruí, en orden cronológico, qué ocurrió (quién, qué, cuándo, desde dónde).
2. Indicá si hubo un incidente de seguridad y de qué tipo.
3. Proponé una hipótesis de contención.
4. Señalá explícitamente qué partes de tu reconstrucción son inferencias que el log no
   muestra de forma directa.
```
